# Savana Product Scraper

## 📖 Overview

This project is a Python-based web scraping solution developed to extract product information from the Savana platform. The scraper collects structured product data and processes it efficiently for analysis, research, and business applications.

The project demonstrates real-world web scraping techniques, data extraction, response processing, and clean Python development practices.

---

## 🚀 Features

* Automated product data extraction
* Structured data collection
* Product details scraping
* JSON data processing
* Error handling and logging
* Scalable scraping workflow

---

## 🛠️ Technologies Used

* Python
* Requests
* JSON
* XPath
* Logging

---

## 📊 Extracted Data

* Product Name
* Product URL
* Brand Name
* Category
* Price
* Discount Information
* Product Description
* Product Images

## ⚡ Installation

```bash
pip install -r requirements.txt
```

---

## ▶️ Run Spider

```bash
scrapy crawl savana_product
```

---

## 📂 Export Output

```bash
scrapy crawl savana_product -o products.json
```
